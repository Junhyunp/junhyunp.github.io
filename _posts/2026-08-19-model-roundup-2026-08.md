2026년 8월 13일 하루에 발표가 넷 겹쳤습니다. [Gemini 3.7 Flash](/posts/gemini-37-flash/)는 따로 다뤘으니, 나머지 셋을 봅니다.

한데 모아놓고 보니 공통점이 하나 있었습니다. **셋 다 "더 똑똑한 모델"을 내세우지 않았습니다.**

![img_file](/assets/img/post/model-roundup-2026-08/three-axes.svg){: .align-center}*세 건을 축별로 정리해 직접 그렸습니다*

## 축 1 · 오픈 웨이트 — DeepSeek V4 Pro 0813

DeepSeek 이 V4 Pro 를 프리뷰에서 정식으로 올리면서 **가중치를 공개**했습니다.

[공식 모델 카드](https://huggingface.co/deepseek-ai/DeepSeek-V4-Pro-0813) 기준으로 **1.7T 파라미터**, **MIT 라이선스** 입니다. 높은 추론 강도에서는 최대 출력 384K 토큰을 권장한다고 적혀 있습니다.

모델 카드는 이번 판을 이렇게 설명합니다.

> 프리뷰 버전을 대체하는 DeepSeek-V4-Pro 의 정식 릴리스이며, **에이전트 능력이 크게 향상**되고 특히 실제 운영 환경에서 성능 개선이 두드러진다.
{: .prompt-info }

MIT 라이선스로 1.7T 모델의 가중치가 공개된다는 게 이 소식의 핵심입니다. 물론 받아서 돌리는 건 다른 문제입니다 — [Simon Willison](https://simonwillison.net/2026/Aug/12/deepseek-v4-pro-0813/)이 적어둔 가중치 크기가 **893GB** 입니다. 개인이 감당할 규모가 아닙니다.

> 파라미터 수를 놓고 2차 출처들이 1.6T·1.57T 로 엇갈립니다. **공식 모델 카드가 적은 값은 1.7T** 입니다. 이런 건 원문을 여는 것 외에 방법이 없습니다.
{: .prompt-warning }

## 축 2 · 속도 — GPT-5.6 Sol Ultrafast

OpenAI 가 Cerebras 칩으로 같은 모델을 더 빠르게 돌리는 티어를 예고했습니다.

[Cerebras 공식 블로그](https://www.cerebras.ai/blog/accelerating-gpt-5-6-sol-ultrafast-with-openai) 기준 **출력 초당 750 토큰** 이고, "품질 저하 없이"라는 단서가 붙습니다. 모델을 바꾼 게 아니라 **같은 모델을 다른 하드웨어에서 돌린** 것입니다.

발표가 든 비교는 이렇습니다.

> Ultrafast 모드의 GPT-5.6 Sol 은 Humanity's Last Exam 2,500문항 전체를 **11시간 11분**에 끝냈다. Claude Fable 5 는 **78시간 27분**이 걸렸다.
{: .prompt-info }

**아직 쓸 수 있는 게 아닙니다.** 공식 문구가 "일부 고객을 대상으로 한 제한 프리뷰"이고, **가격은 공개되지 않았습니다.**

## 축 3 · 맥락 — ChatGPT Computer History

세 번째는 모델이 아니라 기능입니다. ChatGPT 맥 앱이 **내 컴퓨터 활동을 기억으로 만드는** 기능을 열었습니다.

[OpenAI 공식 문서](https://learn.chatgpt.com/docs/customization/computer-history) 기준입니다.

| 항목 | 내용 |
|---|---|
| 기록하는 것 | 클릭, 타이핑, 단축키, 앱 전환 (macOS 접근성 API 경유) |
| 기록하지 않는 것 | 스크린샷, 마이크 입력, 시스템 오디오 |
| 시크릿 브라우징 | **절대 포함되지 않음** |
| 기본값 | **꺼져 있음** |
| 대상 | macOS 데스크톱 앱 · Pro/Business/Enterprise |
| 제외 지역 | EEA, 스위스, 영국 |

통제 수단도 문서에 적혀 있습니다. 어떤 앱·사이트가 기록에 들어갈지 고르고, 일시정지하거나 끄고, 항목별 또는 기간별로 지울 수 있습니다.

그런데 문서에 이런 경고가 함께 있습니다.

> Computer History 파일은 **민감한 정보를 담을 수 있습니다.** 이 파일들은 Computer History 에 의해 **암호화되지 않으며**, 같은 macOS 사용자로 실행되는 다른 프로그램이 접근할 수 있습니다.
{: .prompt-warning }

**OpenAI 가 자기 문서에 직접 적어둔 내용**입니다. 기본이 꺼짐이고 통제 수단이 촘촘한 것과, 켜고 나면 평문 파일이 남는다는 것은 별개의 이야기입니다.

## 세 가지를 겹쳐 보면

셋의 자랑거리가 전부 다릅니다.

| | 내세운 것 |
|---|---|
| DeepSeek | 받아서 직접 돌릴 수 있다 |
| OpenAI × Cerebras | 같은 품질을 더 빠르게 |
| OpenAI (Computer History) | 내 맥락을 안다 |

**"우리 모델이 더 똑똑하다"가 없습니다.** 벤치마크 점수를 올리는 경쟁만으로는 차이를 만들기 어려워졌고, 그래서 접근성·속도·맥락처럼 다른 축으로 벌어지는 중이라고 읽었습니다.

여기까지가 제 해석입니다. 세 회사가 그렇게 말한 건 아닙니다.

## 읽을 때 붙여야 할 단서

**수치는 전부 발표 주체가 낸 것입니다.** 특히 Cerebras 의 속도 비교는 자사 칩을 파는 회사가 경쟁 모델과 견준 것이라, 조건과 설정이 공개되지 않은 상태에서 그대로 옮기기엔 이릅니다.

**Ultrafast 는 아직 상품이 아닙니다.** 제한 프리뷰이고 가격이 없습니다. "초당 750토큰"을 지금 쓸 수 있는 사양으로 읽으면 안 됩니다.

**Computer History 는 한국에서 쓸 수 있습니다.** 제외 지역이 EEA·영국·스위스라 한국은 대상입니다. 개인정보 규제가 강한 지역만 빠졌다는 점을 어떻게 읽을지는 각자 판단할 몫입니다.

**DeepSeek 의 컨텍스트 길이는 확인하지 못했습니다.** 2차 출처는 1M 이라고 적지만 공식 모델 카드에서 찾지 못해 이 글에는 넣지 않았습니다.

## 정리

같은 날 나온 세 건이 서로 다른 축에 서 있습니다.

DeepSeek 은 1.7T 가중치를 MIT 로 풀었고, OpenAI 와 Cerebras 는 같은 모델을 초당 750토큰으로 돌리는 티어를 예고했으며, ChatGPT 맥 앱은 사용자 컴퓨터 활동을 기억으로 삼기 시작했습니다.

세 번째가 가장 조심스럽습니다. 기본이 꺼져 있고 통제 수단이 있다는 점은 분명하지만, **켠 뒤에 남는 파일이 암호화되지 않는다는 것도 같은 문서에 적혀 있습니다.** 켜기 전에 그 문장을 읽는 편이 좋겠습니다.

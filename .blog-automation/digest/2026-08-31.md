### 1. Heretic — 안전 정렬을 자동으로 제거하는 오픈소스 도구

**무엇**
Heretic 은 트랜스포머 기반 언어모델에서 재학습 없이 안전성 정렬(거부 응답)을 자동으로 제거하는 도구다. 제한 프롬프트와 비제한 프롬프트 사이 은닉 상태 차이("residual direction")를 계층별로 계산해 방향성 어블레이션(directional ablation)을 적용하고, Optuna(TPE) 기반 자동 탐색으로 거부율과 원본 대비 KL divergence를 동시에 최소화한다. Dense·MoE·멀티모달 모델까지 지원한다고 한다. GitHub 트렌딩 1위권, 오늘 하루 485 스타 증가.

**출처**
- [GitHub - p-e-w/heretic](https://github.com/p-e-w/heretic) — 1차 출처(공식 레포). **직접 열어** 기법(directional ablation + Optuna 최적화 루프), 라이선스(AGPL-3.0), 지원 아키텍처(dense/MoE/멀티모달)를 확인했다. 누적 별 29.1k.
- 1차 출처: 위와 동일(공식 레포 README).

**왜 쓸 만한가**
이 블로그가 temperature-top-p, hallucination 글에서 다룬 "모델이 확률적으로 어떻게 행동하는가" Concept 축의 반대편 사례다. "왜 모델이 특정 답을 거부하는가"를 방향 벡터라는 구체적 메커니즘으로 설명할 수 있어, 정렬(alignment) 개념 글의 실증 자료로 쓰기 좋다.

**검증** — 확인됨
README 를 직접 열어 기법 설명·라이선스·스타 수를 확인했다. README 가 주장하는 "커뮤니티가 5,000개 이상의 파생 모델을 만들었다"는 수치는 저장소 자체 서술이며 외부 집계로 재확인하지 못했다.

**주의**
안전 정렬 제거 도구를 다루는 글이므로, 소개할 경우 오남용 소지와 책임 있는 사용 맥락을 반드시 함께 언급해야 한다. sources.yml 의 caution 항목은 아니고(이 소스에서 발견한 게 아니라 GitHub 트렌딩에서 직접 발견), 이번 브리핑에서 새로 붙이는 주의사항이다.

**분류안** — Tech, prefix: LLM (정렬/거부 메커니즘의 반례로 Concept 글에도 쓸 수 있음)

### 4. TaoLive Digital Avatar — 하네스가 스스로 진화한다는 기술보고서 (하네스 연작 5편 후보)

**무엇**

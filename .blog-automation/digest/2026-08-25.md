### 2. ARIS — 클로드와 GPT가 서로 의심하며 연구하는 하네스

**무엇**
ARIS(Autonomous Research via Adversarial Multi-Agent Collaboration, arXiv 2605.03042, 2026-05)는 자율 ML 연구를 위한 오픈소스 하네스다. 실행자(Claude)가 연구를 진행하고, 다른 모델 계열의 리뷰어(GPT)가 중간 산출물을 비판·수정 요구하는 구조 — "같은 모델의 자기수정으로는 못 잡는 상관 오류를 다른 모델 계열이 잡는다"는 것이 핵심 주장이다. 65개 이상의 마크다운 정의 스킬, 5개 종단 워크플로우, 증거→주장 매핑을 검사하는 3단계 감사(assurance) 체계를 갖췄다.

**출처**
- 1차 출처: [wanshuiyin/Auto-claude-code-research-in-sleep](https://github.com/wanshuiyin/Auto-claude-code-research-in-sleep) — 공식 구현 레포. **직접 열어** 논문(arXiv 2605.03042) 링크, 저자/기여자 목록, 스타 15.1k·포크 1.3k 를 확인했다.
- 논문: arXiv 2605.03042 "ARIS: Autonomous Research via Adversarial Multi-Agent Collaboration" — **원문 초록 페이지는 EGRESS_BLOCKED 로 못 열었다.** HuggingFace 논문 페이지 요약과 WebSearch 스니펫으로 방법론 개요만 파악.

**왜 쓸 만한가**
이 블로그의 하네스 연작(#34 Prime Agent, #35 Continual Harness, #36 harness-search, harness-engineering)의 자연스러운 다음 편이 될 수 있다. "다른 모델 계열이 서로를 검증한다"는 cross-model adversarial 구조는 앞선 글들의 self-refinement/진화 탐색 접근과 각도가 다르다.

**검증** — 확인됨(레포 기준) / 미확인(논문 세부)

### 3. HarnessEval-W — 하네스를 월드모델 평가로 옮기다

**무엇**
HarnessEval-W(Agentifying the Evaluation of Visual Worlds, arXiv 2608.16859, 2026-08-18, MirroS Lab)는 LLM 에이전트 생태계의 "하네스" 패러다임을 월드모델(비디오 생성 모델) 평가로 옮긴 시도다. 고정된 채점 기준 대신, 평가 질문을 측정 가능한 하위 질문으로 쪼개 전담 서브에이전트가 각자 근거를 모으고, 상위 에이전트가 그 근거를 검증해 최종 판정을 내린다. 물리·인과·세계 상태가 제대로 이어지는지를 사람이 검증 가능한 "근거 트리"로 남기는 게 핵심.

**출처**
- 1차 출처: [MirroS-Lab/HarnessEval-W](https://github.com/MirroS-Lab/HarnessEval-W) — 공식 레포. **직접 열어** arXiv 2608.16859 링크, MirroS Team 저자 표기, 스타 259·포크 7 을 확인했다.
- 논문: arXiv 2608.16859 — **원문은 EGRESS_BLOCKED 로 못 열었다.** 레포 README 요약과 WebSearch 스니펫에 따르면 18개 월드모델·330개 평가 케이스에 적용했다는 주장이 있으나, 정확한 산출 방식은 README 에도 명시돼 있지 않았다.

**왜 쓸 만한가**
"하네스"라는 개념이 LLM 에이전트를 넘어 다른 모달리티(비디오/월드모델) 평가로 확장되는 사례다. 하네스 연작의 다음 편이면서, "하네스가 원래 무엇인가"를 다시 설명하는 훅으로도 쓸 수 있다.

**검증** — 확인됨(레포 기준) / 미확인(수치 세부)
레포는 직접 확인했다. "18개 모델·330개 케이스"는 WebSearch 스니펫에서만 나왔고 레포 README 자체에는 정확한 수치가 없었다 — 논문 원문에서 재확인 필요.
